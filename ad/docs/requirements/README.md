## 读完 requirements/ 应该能回答

- 这个项目**做什么、不做什么**？
- 目标用户是谁？**三个岗位**各自干什么？
- 核心业务链路是什么？**一张订单从创建到完成经过哪些节点**？
- 哪些**业务规则**是硬性要求（版本 append-only、所有物料确认后订单才完成……）？
- 有什么**明确不做**的（合同/支付/在线图片编辑/真实邮件……）？

**不能回答**（留给 design/）：
- 数据库表怎么设计？
- 接口叫什么？
- 页面长什么样？
- 用什么技术栈？
